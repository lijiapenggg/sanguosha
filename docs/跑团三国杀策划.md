# 跑团三国杀 · 游戏规则策划（线下执行版 v0.3）

> 定位：**线下桌游规则框架**。网页（sanguo.zeabur.app）仅作电子牌桌：展示手牌、发身份牌、
> 回合轮转、卡牌指向、HP 记录。判定细节采用团内既有规则（含龙城卡的属性/特质体系），
> 本文档定义大方向与本次确认的具体规则。冲突时以 GM 裁定为准。

---

## 〇、网页工具管什么 / 不管什么

| 网页负责（自动化） | 线下负责（GM + 既有规则） |
|---|---|
| 5 人房间、就位、发身份牌 | 攻击/防御/豁免/伤害等一切判定 |
| 身份保密（本人与 GM 可见）与主公展示 | 龙城卡属性、特质触发与效果 |

| 打牌时指向目标（箭头全员可见） | 距离判定、最终仲裁 |

## 一、玩家规则

### 1.1 角色与血量（上百血量，DND 量级）
- 角色 = 一张**龙城卡**，形象上传网页头像位。
- **血量上限 = 龙城卡血量**；开局把网页"体力上限"填为龙城卡血量，当前值 = 满血。
- **掉血方案（数值扣减）**：所有伤害由 GM 按既有判定规则结算为具体数值（如杀 1d10+修正、范围 6d10），GM 宣布后玩家同步点击网页 HP 扣减。
  
  - 健康：HP > 50%；手牌上限4
  - 受伤：25% < HP ≤ 50%；手牌上限2
  - 重伤：HP ≤ 25%；手牌上限1
- 濒死/死亡：HP ≤ 0 进入濒死（可用【桃】救回至 1）；无人救则倒下。

### 1.2 主公血量
- **主公血量上限 = 龙城卡血量 + 固定加成30**

- 主公额外获得1手牌上限。

- 身份局中主公死亡即触发胜负结算（见 §3.4）。

### 1.3 属性与特质
- 沿用龙城卡，细节由团内既有规则执行（本策划不展开）。

## 二、手牌规则（牌 = 行动）

### 2.1 牌种 → 动作 对照表

| 牌种 | 动作 / 效果 |
|---|---|
| 【杀】/【雷杀】 | **攻击动作**：指定目标（网页箭头），只有打出杀才能执行攻击动作 |
| 【闪】 | **防御**：仅在被攻击或被强迫豁免时打出（两种效果见 §2.2） |
| 【桃】 | 恢复生命4d10 / 濒死急救4d10 |
| 【酒】 | 本回合下一次【杀】增伤2d8；或濒死自救4d10 |
| 【决斗】 | 单挑：目标与你交替打出【杀】，先拿不出者视为受到多重攻击或者伤害特质。 |
| 【南蛮入侵】 | **对除你外的所有玩家直接造成 6d10 力场伤害** |
| 【万箭齐发】 | 同上：直接 6d10 伤害 |
| 【桃园结义】 | 全体恢复4d8血量 |
| 【五谷丰登】 | 翻开等同人数张牌，从你起轮流各选一张 |
| 【无中生有】 | 摸 2 张 |
| 【无懈可击】 | 抵消一张锦囊（可连锁） |
| 【过河拆桥】 | 弃置目标一张牌（手牌/装备） |
| 【顺手牵羊】 | 获得目标一张牌（手牌/装备） |
| 【火攻】 | 对目标造成10d6火焰伤害（判定按既有规则） |
| 【铁索连环】 | 令目标进入"连环"：属性/火雷伤害传导 |
| 【乐不思蜀】 | 判定生效则目标跳过出牌阶段 |
| 【兵粮寸断】 | 判定生效则目标跳过摸牌阶段 |
| 【闪电】 | 判定生效则目标受到血量上限的一半雷伤 |
| 武器 / 防具 / 马匹 | 装备，见 §2.4（距离判定与三国杀一致） |

### 2.2 【闪】的两种触发
- **被攻击时**（对方打出【杀】/攻击检定指向你）：打出【闪】→ 本次**你的 AC 临时 +5，持续至当前玩家回合结束；
- **被强迫豁免时**（规则要求你进行豁免检定，如强制豁免效果）：打出【闪】→ 本次豁免获得**优势（双投取高）且豁免骰额外 +1d4**。
- 同一张【闪】只能响应一次触发；是否可对【南蛮】【万箭】打出由 GM 裁定（默认不可，见 §2.3）。

### 2.3 【南蛮入侵】【万箭齐发】= 直接伤害
- **不做豁免**：对除你以外的所有玩家**直接造成 6d10 伤害**。

### 2.4 装备（距离判定与三国杀一致）

**距离基础规则**：座位相邻距离为 1，取最短方向；武器自带攻击距离（下表）；马匹修正距离（+1 马使你更难被攻击，-1 马使你更容易攻击到别人）。

**武器（原版效果 + 扩展效果）**

| 武器 | 攻击距离 | 原版效果 | 扩展效果 |
|---|---|---|---|
| 诸葛连弩 | 1 | 出【杀】无次数限制 | —（已覆盖"多段攻击"） |
| 青釭剑 | 2 | 无视目标防具 | 攻击检定无视目标防具带来的 AC 加成 |
| 雌雄双股剑 | 2 | 杀异性目标：目标弃 1 牌或你摸 1 | 保留；命中异性目标后再触发一次该选择 |
| 寒冰剑 | 2 | 杀造成伤害时，可防止伤害改为弃目标 2 牌 | 保留 |
| 青龙偃月刀 | 3 | 杀被【闪】抵消时，可再打 1 张杀追击 | 保留 |
| 丈八蛇矛 | 3 | （原版：两张手牌当杀） | **弃两张手牌 → 获得 1 次额外攻击次数**（每回合发动次数 GM 定，默认不限但需有牌可弃） |
| 贯石斧 | 3 | 杀被【闪】抵消时，弃 2 牌强制造成伤害 | 保留；或改为"弃 2 牌使该次攻击无视 AC 命中"（GM 定） |
| 朱雀羽扇 | 4 | 普通杀可当火杀 | **你造成的所有伤害可转换为火焰伤害**（可与藤甲/铁索联动） |
| 麒麟弓 | 5 | 杀造成伤害时弃目标 1 匹马 | 保留 |
| 古锭刀 | 2 | 对无手牌目标视为重击| 保留 |

**防具（原版效果 + AC 加成）**

| 防具 | AC 加成（推荐，可调） | 原版效果 |
|---|---|---|
| 八卦阵 | +1 | 需打【闪】时判定：红色视为闪 |
| 仁王盾 | +2 | 黑色【杀】对你无效 |
| 藤甲 | +2 | 普通杀/南蛮/万箭对你无效；获得火焰易伤 |
| 白银狮子 | +1 | 你获得一次免死，免死触发后弃置此牌。当此牌离开你的装备区时，你恢复4d10血量。|

**马匹（与原版一致）**

| 马匹 | 效果 |
|---|---|
| +1 马（的卢/绝影/骅骝） | 其他玩家对你计算攻击距离 +1 |
| -1 马（赤兔/大宛/紫骍） | 你对他人的攻击距离 -1 |

## 三、游戏进行规则

### 3.1 开局流程
1. 5 人就位（网页）；
2. GM 发身份牌：1 主公、2 反贼、1 忠臣、1 内奸（网页随机）；
3. 当前回合玩家点击"将回合交给主公并展示主公身份"（网页）——**第一回合从主公开始**；
4. 每人把龙城卡血量（主公含加成）填入网页体力上限，GM 核对特质与装备，开局。

### 3.2 回合结构（每回合五阶段）
1. **回合开始**：结算开始阶段效果（乐不思蜀/兵粮寸断/闪电判定；特质触发）；
2. **摸牌阶段**：摸 2 张；
3. **出牌阶段**：自由打牌、装备、用锦囊、发动主动特质、与队友协商；
4. **弃牌阶段**：手牌 > 上限（§1.4）时弃置；
5. **回合结束**：结算结束阶段效果，交下家（网页）。

### 3.3 手牌规则
- 基础每回合【杀】限 1 次，可以发动多重攻击；装备【诸葛连弩】后不限，每多出一张杀视为使用一次额外攻击；【丈八蛇矛】可弃牌换额外攻击次数。使用攻击类特质，本回合需出【杀】，否则无法使用。
- 需要目标的牌必须**指定目标**并用网页箭头指向，GM 确认后生效。
- **距离**：按 §2.4 规则计算，不满足距离无法以该目标为攻击对象，除此之外，aoe特质按照特殊规则结算：
1.圆形aoe，目标为你指定的目标+左右两人
2.锥形和直线型，矩形aoe 目标为你指定的目标+顺时针2人
3.若aoe范围超过60尺及以上，视为对所有玩家发动。
- 【特殊规则】召唤流：召唤流在本游戏中正常召唤生物，但需要将召唤物置于自己的头像之上。为此获得以下效果：
1.头像上每有一个召唤物，手牌上限+1
2.召唤流玩家出杀时，可以放弃本体攻击的机会，让一个召唤物出击。同时只能有一个召唤物进行攻击。


### 3.4 胜负条件（身份局）
- **主公死亡** → 反贼获胜；若主公死亡时仅剩内奸存活，则**内奸获胜**；
- **反贼全灭** → 主公与忠臣获胜；
- **内奸成为最后存活者** → 内奸获胜；
- 忠臣死亡不影响胜负判定。
